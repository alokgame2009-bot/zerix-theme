# Zerix V4 UI specification

## Client
- Login / register / password recovery visual system
- Sidebar + compact navigation
- Dashboard server cards/list
- Server overview
- Console
- Files
- Databases
- Schedules
- Backups
- Network
- Startup
- Server settings
- Account/profile settings

## Admin
- Dark admin shell
- Cards, tables, forms, buttons and alerts
- Responsive layout
- Same accent variables as client UI

## Visual system
- Dark navy/black surfaces
- Purple/blue accent
- 12–16px card radius
- Subtle borders
- Soft elevation
- Responsive mobile breakpoints
- CSS variables for customization
