# ZERIX Theme 2.0
Modern dark/glass visual layer for Pterodactyl.

## One command
`bash <(curl -fsSL https://raw.githubusercontent.com/alokgame2009-bot/zerix-theme/main/zerix.sh)`

Menu: Install, Uninstall, Update, Exit.

## Notes
Creates a timestamped backup of `resources/scripts/index.tsx` before changes. ZERIX 2.0 focuses on a modern dashboard/admin visual system while preserving Pterodactyl's existing React functionality.
